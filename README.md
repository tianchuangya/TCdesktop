# TCdesktop · 云屿 / Orbit

> 一个把 Windows 桌面替换成「沉浸式桌面管理器」的 Electron 应用 —— 粒子化动态壁纸、项目即星系、3D 空间文件架、液态玻璃小部件，以及一位会看你的 GrokBot AI 助手。

**当前版本**：0.2.0 · **平台**：Windows 10/11（2560×1440 及以下主流分辨率）

TCdesktop 不修改系统内核，而是作为独立 Electron 应用，以主显示器完整尺寸嵌入 Explorer 的 `SHELLDLL_DefView` 桌面层，接管并替换原生桌面。它内置两套皮肤：

- **Orbit（轨道 / 星系）**：粒子化动态壁纸 + 「项目即星系」的 3D 轨道视图 + Three.js 空间文件架。
- **云屿（xinghui）**：液态玻璃（liquid glass）风格的桌面小部件系统 —— 侧边栏、信息流卡片、顶部操作区、时间块、路径浮窗、歌词块，以及可自由组合的「自定义块」。

---

## ✨ 主要特性

- **桌面层接管**：以主显示器完整尺寸嵌入 Explorer 桌面层，隐藏原生桌面图标，退出前自动恢复；托盘提供「恢复 Windows 桌面并退出」。
- **粒子化动态壁纸**：把当前 Windows 壁纸（图片 / MP4 / WebM / Wallpaper Engine）用 WebGL 点阵逐帧重组，支持三维波浪、风场、呼吸与鼠标视差。
- **项目即星系**：自动识别含 `package.json`、`.git`、`pyproject.toml`、`Cargo.toml`、`go.mod`、`.sln` 的项目目录；进入子目录镜头推进，返回上级镜头拉远。
- **3D 空间文件架**：Canvas 纹理贴到 Three.js 平面网格，真实 Z 深度 / 旋转 / 缩放 / 缓动 / 射线点击，中心项带边缘泛光与切换音效。
- **真实文件系统**：读取桌面快捷方式、文件、文件夹与 Windows Shell 真实图标；按项目 / 应用 / 文档 / 媒体 / 压缩包 / 文件夹分类。
- **云屿液态玻璃系统**：玻璃、颜色、圆角、镂空、倾斜均可调；鼠标悬停有水波纹涟漪（liquid ripple）。
- **自定义块**：媒体播放器、图片加载器、音乐播放器、性能监控（CPU / 内存 / 网速）、快捷方式启动器、文本播放器、AI 调用器，可自由摆放、缩放、倾斜。
- **GrokBot AI 助手**：一只会眨眼、会转向鼠标的虚拟伙伴；接入任意 OpenAI 兼容接口（自定义 key / baseUrl / model），流式对话。
- **指令台**：`cd` / `dir` / `ls` / `open` / `copy` / `pwd` / `cls` / `theme`。
- **样式仓**：极昼、余烬、引力紫三套预设；壁纸不透明度、粒子密度、运动强度、透视、字体、颜色等细粒度可调；支持 JSON 导入导出。

## ⌨️ 快捷键与手势

### 全局键盘

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + K` / `` Ctrl + ` `` / `Ctrl + Alt + T` | 打开搜索 / 指令台 |
| `Ctrl + N` | 新建文件 / 文件夹对话框 |
| `Alt + ←` | 返回上一级目录 |
| `F2` | 固定 / 解除全部界面（UI 常驻） |
| `↑` / `↓` | 浏览右侧 3D 文件架 |
| `Enter`（文件架聚焦时） | 打开当前项 |
| `Esc` | 关闭面板 / 抽屉、取消界面固定 |
| `Ctrl + Alt + Shift + O` | 重新绑定桌面层（恢复热键） |
| `Win + D` | 恢复 Windows 桌面表面（应用接管） |

### 鼠标 / 指针手势

| 手势 | 功能 |
| --- | --- |
| `Alt + 左键拖动` | 移动时间块 / 路径块 / 歌词块（歌词开启「自由拖动」后可直接拖） |
| `Ctrl + 右键拖动` | 移动任意块 / 面板（侧边栏、时间、路径、歌词、自定义块、AI 悬浮等）；拖到屏幕顶部删除区可删除自定义块 |
| `Alt + 右键` | 打开当前块设置 |
| 舞台 `左键拖动` | 旋转星系视角 |
| 舞台 `Shift + 左键拖动` | 平移星系中心 |
| 舞台 `右键 + 向左滑（>75px）` | 返回上一级 |
| 鼠标侧键（后退键 / 键 4） | 返回上一级 |
| 路径 `单击` | 复制当前路径 |
| 路径 `双击` | 返回上一级 |
| 文件 `单击` / `双击` / `右键` | 选中 / 打开 / 在资源管理器定位 |

### 自定义图片 / 媒体块

| 操作 | 功能 |
| --- | --- |
| `左键拖动` 图片 / 视频 | 移动画面位置（等比例完整 = 整图摆放；裁剪铺满 = 取景） |
| `Ctrl + 滚轮` | 缩放（仅「裁剪铺满」模式，100%–260%） |

> 「等比例完整」= 整图完整显示、块内自由摆放、不裁切不缩水；「裁剪铺满」= 图片铺满块并按需裁切取景，`Ctrl + 滚轮`放大后再拖可上下左右选景。

### AI 助手（GrokBot）

| 操作 | 功能 |
| --- | --- |
| 点击 GrokBot / 触发入口 | 打开 AI 面板 |
| 输入框 `Enter` | 发送消息 |
| 输入框 `Ctrl + Enter` / `Shift + Enter` | 换行 |
| 点击面板外部 | 关闭面板 |

## 🚀 运行与发行

### 开发运行

```powershell
npm install
npm start
```

或双击 `start-tcdesktop.bat`（自动安装依赖并启动；网络受限时会打开浏览器预览）。浏览器预览使用示例数据，不会读取或打开真实桌面文件。

退出 / 恢复桌面：系统托盘右键 TCdesktop →「恢复 Windows 桌面并退出」。

### 发行版（.exe）

```powershell
npm run dist
```

打包产物输出到 `dist/`（NSIS 安装包 + 免安装 `win-unpacked`）。首次打包会自动下载 Electron 运行时分发文件。

> 提示：TCdesktop 接管桌面层，属于「替换桌面」型工具；如遇桌面图标未恢复，可按下 `Ctrl + Alt + Shift + O` 强制重新绑定，或从托盘菜单恢复。

## 📁 目录结构

```
TCdesktop/
├── main.js                 Electron 主进程：窗口嵌入桌面层、桌面扫描、文件操作、AI 聊天、设置读写
├── preload.js              受限 IPC 接口
├── src/
│   ├── index.html          界面结构
│   ├── styles.css          玻璃、泛光、液态玻璃、AI 面板等全部样式
│   ├── app.js              渲染进程核心：分类、星系导航、指令台、样式、自定义块、粒子运行时
│   ├── grokbot.js          GrokBot 组件（表情 / 状态机 / 视线跟随鼠标）
│   ├── grokbot-data.js     GrokBot 表情数据（25 表情 / 39 状态 / 呼吸 / 眨眼）
│   ├── wallpaper-3d.js     图片/视频纹理采样、WebGL 粒子重建与流场着色器
│   ├── shelf-3d.js         Three.js 空间文件架、射线交互与右缘热区
│   └── assets/wallpapers/  内置壁纸
├── start-tcdesktop.bat     一键启动脚本
└── package.json
```
